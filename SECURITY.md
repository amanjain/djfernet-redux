# Security policy

## Supported versions

Security fixes are released for the latest version of djfernet-redux only. Upgrading
is safe: every release reads data written by earlier versions, djfernet and
django-fernet-fields (see the [changelog](CHANGES.md)).

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/amanjain/djfernet-redux/security/advisories/new),
not in a public issue. Include the affected version, how to reproduce it and the
impact you expect. You'll get a reply there, and the fix and advisory are published
together once a release is ready.
